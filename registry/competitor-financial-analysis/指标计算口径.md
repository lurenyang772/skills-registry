## 指标计算口径

使用以下默认公式；若公司披露口径不同，优先采用公司口径并说明差异：

- 变动额 = 本期值 - 上期值
- 变动幅度 = 变动额 / 上期值；上期值为0或负数时，不直接计算百分比，改用文字说明
- 毛利率 = 毛利额 / 净销售额
- 期间费用率 = 期间费用 / 净销售额（研发、销管分列展示）
- 自由现金流 = 经营活动现金流净额 - 资本支出
- 现金类资产 = 货币资金 + 短期投资/理财；仅在可比口径成立时合并
- 资本支出占收比 = 资本支出 / 净销售额
- Capex/D&A = 资本支出 / 折旧摊销（判断资产净投入状态）
- 销售额/固定资产 = 净销售额 / 平均固定资产；若只能取得期末值，明确标注简化口径
- 人均收入 = 净销售额 / 期末员工数（近似指标）
- 资产摊销周转年限 = 期末固定资产及无形资产 / 折旧与摊销额；仅作近似指标
- 经营现金流/净利润 = 经营活动现金流净额 / 净利润
- 资金覆盖倍数 = 现金类资产 / 金融负债
- 利息保障倍数 = 息税前利润 / 利息支出；无重大付息债务时标注"不适用"
- 股东回报占经营现金流 = 股息与回购 / 经营活动现金流净额
- FCF对股东回报覆盖率 = 累计自由现金流 / 累计（股息+回购）；用于多年期分配合理性判断
- 分部利润率 = 分部营业利润 / 分部净销售额
- 有效税率 = 所得税费用 / 税前利润；异常年份须附备考税率说明

禁止在缺少输入数据时反推、插值或编造结果。
