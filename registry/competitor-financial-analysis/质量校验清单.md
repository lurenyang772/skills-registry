## 质量校验清单

提交前逐项检查：

- [ ] 所有公司名称、股票代码、财年和币种一致（注意境外公司非日历年财年）；
- [ ] 核心数据均有来源，关键数据完成交叉验证；
- [ ] 三大报表及附注之间完成基本勾稽；
- [ ] 计算公式、输入值和结果可复核；
- [ ] 同比基数为0或负数时未错误计算百分比；
- [ ] 分部重述已建立新旧口径映射并统一序列；
- [ ] 回购/分红双口径差异已核对并注明主用口径；
- [ ] 税率异常年份已查明原因并给出备考口径；
- [ ] 已完成指引偏差特征分析（近3年指引 vs 实际）；
- [ ] 资产减值、表外负债和业绩指引均完成专项核查；
- [ ] 正文没有把推断当作事实；框架模型输出均标注"分析判断"；
- [ ] 权重化评分已说明权重依据、评分标准与敏感性；
- [ ] 各章遵循总分总，结论有数据支撑；
- [ ] 表格无重复，表头加粗，单位和小数位统一，推算值已标注；
- [ ] 未引用自媒体、未使用内幕信息、未编造数据；
- [ ] 已注明数据截止日期、局限性和免责声明。
