## 这是什么（与「搜资料」的本质区别）

大多数行业研究 skill 做的是「把信息堆在一起」。本 skill 做的是**透视**——像 X 光一样把行业的骨头（结构）、血液（钱怎么流）、神经（流量怎么走）、地雷（风险在哪）一次看穿，最后落成一张**能做决定的卡片**，而不是一堆看不完的资料。

一句话定位：**输入一个行业名 + 你的目的，输出一张「该不该进、从哪进、怎么避坑」的决策卡。**

核心差异（请在本 skill 的对外介绍中这样讲，避免被误认为同类产品）：
1. **五镜结构，不是线性步骤**：市场 / 竞争 / 供应链 / 流量 / 风险 五面独立成镜，互不替代，最后由决策镜统合。
2. **利润池地图（签名能力）**：不只列竞品，而是画出「钱到底沉淀在产业链哪一环、被谁赚走、新玩家能从哪切一刀」。
3. **决策镜（签名能力）**：6 维加权评分卡 + go/no-go + 90 天行动地图，研究直接导向行动。
4. **置信度引擎（防编造）**：每条关键事实强制标「高/中/低」置信度并附来源；搜不到就登记「数据缺口」，禁止硬编。
5. **反共识检查**：终稿前强制挑战自己的主结论，逼出被叙事掩盖的真风险。
6. **场景自适应**：创业 / 投资 / 择业 / 选品 / 内容 5 套预设，同一框架自动换重心。
