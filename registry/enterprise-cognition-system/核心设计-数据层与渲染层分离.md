## 核心设计：数据层与渲染层分离

这是整套方法论的地基，缺了它迭代必然失控。

| 文件 | 职责 | 迭代时 |
|---|---|---|
| `_data.py` | 全部研究内容与未核实项清单 | **只改这里** |
| `_build.py` | 读取 `_data.py`，同时输出 HTML 与 Word | 不动 |

生成命令：`python _build.py vN`（N 递增，永不覆盖旧版本，保留版本序列以供对照）。

数据结构（`_data.py`）：

```
VERSION / TITLE / SUBTITLE
META    = 一句话定性 / 当前核心矛盾 / 三个必答问题
KPIS    = [(指标名, 数值, 说明, 方向up|down|warn|flat), ...]
SECTIONS= [{id, title, blocks:[...]}, ...]
```

`blocks` 支持七种类型，HTML 与 Word 共用同一渲染器：
`h3` `h4` `para` `note`（研判段，视觉上单独区分）`bullets` `table`（headers + rows）`two_col`（左右对照，用于多空、优劣）
