## 技术坑（已踩过）

- **Windows 日期格式**：`strftime("%-m")` 无效。用 f-string 直接取 `.year` `.month` `.day`。
- **Word 中文字体**：必须同时设 `run.font.name`（西文）与 `rFonts` 的 `w:eastAsia`（中文），否则中文回退成默认字体。研判段落用楷体加缩进加棕色，不加标签式前缀。
- **HTML 导航标题**：截中文序号不要用 `split("、",1)[-1]`（章标题内部含"、"时会把"治理、法律架构与股权"错截成"法律架构与股权"）。用正则 `re.sub(r"^[一二三四五六七八九十]+、", "", t)` 去序号，再 `t.split("（")[0].split("：")[0]` 去括号注与副题，最后限长（超10字加"…"），避免截在括号或标点中间。
- **硬约束自检脚本化**：交付目录放一个 `_check.py`，用 python-docx 提取 Word 全文（含全部表格 cell）+ 读 HTML 源码，正则扫描禁用模式（【】「」、机构名、人名、AI套话），每轮迭代后必跑、零命中才算完成。这是自动化迭代可复用的闭环验证。
- **涨红跌绿**：中国用户语境下，指标向好用红色、恶化用绿色，并额外提供"上行/下行/警示/持平"文字标签以消除歧义。
- **批量改 `_data.py` 的补丁脚本三件套**：① 动手前先备份（`_data.py.bak_vN`）；② 每条替换都要断言 `count == 1`，且锚点必须带足够前缀——结论句常在多个章节里重复出现（同时出现在竞争章与误读章），短锚点会一次命中多处，改错章节；③ 落盘前必须 `ast.parse(src)` 再 `write`，语法错就整轮白做（文件未写，重跑即可）。
- **补丁文本里的中文引号**：往 `_data.py` 写入的中文正文若含 ASCII 双引号，会提前终止目标文件里的字符串字面量，报出的是毫不相干的 `invalid character` 行号。写法是把待插入文本统一过一遍归一化函数（按奇偶把 ASCII 双引号转成全角 `“”`，并断言数量为偶数），再拼进字符串。注意区分两类 ASCII 引号：正文里的属于要转换的，列表/字典结构里的（表格行 `["a","b"]`）必须保持 ASCII 原样。
- **归一化函数只能用于纯正文载荷**：要插入的是完整章节块（形如 `{"t":"h4","x":"…"},{"t":"para","x":"…"},`）时，其 ASCII 引号属于结构、必须原样保留，**不能**走归一化，否则断言直接失败（`ascii dquote in payload`）。做法是这类载荷用裸三引号（`X = """…"""`）定义并让末尾自带 `"}`，正文型载荷才过归一化。同类坑：写完载荷后如果末尾漏了 `"}`，插入后会变成 `…。,\n`，`ast.parse` 报“unterminated string literal”，指到后面的无关行。
- **列表内追加块时锚点必须含原有尾部 `}`**：把新块插到列表末元素之后时，若锚点只取到 `…。"` 而不含那个 `}`，替换后会残留一个多余的 `}`，报错是 `closing parenthesis '}' does not match opening '['`，且行号指向后续若干章节，极易误判。正确做法是把锚点延长到 `…。"}\n        ],`，替换串里自带完整闭合。
- **警惕“替换为自身”的空操作 rep**：写补丁时若留了一条把 `…。"` 换成 `…。` 的检查性替换（丢了尾部引号），会静默破坏 JSON 结构，直到最后 `ast.parse` 才报错。写完脚本先通读一遍所有 `rep()` 的 new 参数是否完整，再运行。
