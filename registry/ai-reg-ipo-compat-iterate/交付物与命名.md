## 交付物与命名

- `v{n}_YYYY-MM-DD_HH-MM.html` + 同名 `.docx`（由同版 HTML 派生，保证双交付物一致）
- 生成器 `_gen_word_v{n}.py`；构建脚本 `_build_v{n}a..f.py`；校验脚本 `_check_v{n}.py`
- 更新 `_iter_meta.json`（**先备份** `_iter_meta_backup_pre_v{n}.json` 并记录 sha256）
- 追加 `.workbuddy/memory/YYYY-MM-DD.md` 与 automation memory
- 最后 `present_files` 交付 HTML + docx（漏掉这一步用户拿不到文件）
