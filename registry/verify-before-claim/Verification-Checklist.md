## Verification Checklist

- [ ] 检查器跑过阴性对照且确实报 FAIL；每条结论都有命令与原始输出片段
- [ ] 验证走**独立通道**（不是产出该改动的同一条路径）；多通道已查**通道独立性**并按**少数否决**聚合
- [ ] 结论已写明**一致性的来源与剩余盲区**；同源的「一致」未被写成「已交叉验证」
- [ ] 涉及远端 / 接口时，已排除探测手段本身失效（第 6 类）
- [ ] 断言有锚：能指出**对象标识**、**范围可枚举**、**有读取时刻**（第 7 类）
- [ ] 换了环境 / 沿用他人证据，已比对**环境指纹**关键项（有差异即重跑，不沿用旧结论）
- [ ] 结论明确落在**一态**上（已证 / 已证伪 / 无法判定），没被含糊成一句「做完了」；无法验证的部分已显式声明为「未验证」
- [ ] 要交付 / 留档的结论已落成**证据包**（命令 + 输出哈希 + 对照 + 时刻齐备），第三方可离线复跑
