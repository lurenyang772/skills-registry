## 二、调用

`cwd` 必须是 `<plugin_root>/skills/html-to-docx/scripts`（`html_to_docx` 包在此）。

```powershell
Push-Location "<plugin_root>\skills\html-to-docx\scripts"
& "$venv\Scripts\python.exe" -m html_to_docx convert <input.html> -o <output.docx> `
    --page-size A4 --orientation portrait
Pop-Location
```

成功判据：stdout 为 JSON 且 `"success": true`，**且退出码 0**。`warnings` 必须为空（有 warning 就说明有区域/锚点没解析，别当成功）。

> Windows 侧执行提示：本机 Git Bash 的 PATH 常为空（`ls: command not found`），且 PowerShell 的 stdout 不回传。稳妥做法是 PowerShell 里把输出重定向到 `$env:TEMP\xxx.txt` 再用 Read 工具读取；包含内联双引号的命令易被沙箱解析失败，改用单引号或 here-string。
