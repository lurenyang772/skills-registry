## 作业流程

1. **提取核心主张** — 拆成"谁 / 何时 / 何地 / 发生了什么 / 什么数据 / 由谁证实"的可验证命题，逐条编号。
2. **检查信息完整性** — 原链接是否存在、发布账号与时间、截图是否缺上下文、视频是否完整、标题与正文是否一致。缺料时先完成能完成的核验，再列出补料清单。
3. **追溯最早来源** — 找最早可确认发布记录、原始文件、完整影像；建立传播链：`原始材料 → 首次转述 → 媒体报道 → 自媒体改写 → 当前流传版本`。
4. **核对时间线** — 旧闻翻炒、时区误读、人物当时是否具备所声称身份。
5. **交叉验证** — 至少两类相互独立的证据；单一来源要显著降低置信度。
6. **影像/音频核验** — 反向图搜、关键帧、地标路牌天气阴影口音、元数据、剪辑配音、AI 生成迹象。
7. **数据核验** — 出处、口径、样本量、分母、图表坐标、同行评审、撤稿勘误、相关≠因果。
8. **主动找反证** — 权威更正、当事人否认、原作者澄清、更合理的替代解释。
